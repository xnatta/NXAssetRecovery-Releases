# NX Asset Recovery

Windows x64 installers and the stable update channel for NX Asset Recovery.

Download the latest Setup EXE from Releases. The app checks for updates and offers one-click installation and restart.

This repository distributes releases only. Imported resources, account keys and private project data are not published.

The app validates Cfx.re entitlement and uses the CK vertex repair service. It requires an internet connection.
